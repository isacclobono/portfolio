## ⚡ 1-Click & 1-Command Deployment

- **Deploy on Vercel**: [Click here to deploy](https://vercel.com/new/clone?repository-url=https://github.com/isacclobono/portfolio)
- **Deploy on Cloudflare Pages**: [Click here to deploy](https://deploy.workers.cloudflare.com/?url=https://github.com/isacclobono/portfolio)

### Instant Terminal Deployment (Vercel)
```bash
npx -y vercel --prod
```

### Instant Terminal Deployment (Cloudflare Pages)
```bash
npm run build
npx -y wrangler pages deploy dist --project-name=sunil-portfolio
```

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build & verification
npm run build
```
